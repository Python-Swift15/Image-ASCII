# 🖼️ Python Image → ASCII

A Duke of Edinburgh Bronze Skills project to build a Python program that turns user-selected images into 2D ASCII art.

`🐍 Python` · `🖼️ 2D ASCII art` · `🏅 DofE Bronze`

## 🎯 Goal

By the end of my DofE Skills activity, I aim to build a Python program that lets someone choose a JPG or PNG image and see a recognisable 2D version made from text characters. I'll test it with at least three different images and use this README to record what I learn, what I change, and how I solve problems.

## ⚙️ How it could work

1. Open the image the user chooses.
2. Resize it and convert it to grayscale.
3. Match each pixel's brightness to a character, such as `@` for darker areas and `.` for lighter areas.
4. Display the characters in rows of text to recreate the image.
